## Resume integrity rules

1. **New workspace:** initialize `Package version` and `Package/archive SHA-256` from the current reference package before doing Play 0 work.
2. **Blank or mismatched identity:** stop without changing status, artifacts, or editable copies. Record the mismatch outside the workspace if necessary and ask the owner whether to resume with the recorded package or run a separately approved migration.
3. **Artifact verification:** for every play marked `PASS`, verify that its named artifact exists and still passes that play's gate.
4. **Earliest-safe rewind:** if an artifact is missing or invalid, preserve all files/evidence, set the earliest affected producing play to `REWRITE`, set every later `PASS` play to `BLOCKED`, and resume at the first action that can recreate/revalidate the artifact. Never silently retain downstream `PASS` states.
5. **Contradictory state:** if current play/action, gate states, artifacts, or next action disagree and no single earliest invalid artifact resolves it, stop without mutation and ask the owner to reconcile the record.
