# Ingest Me First

Status: `ENGLISH AUTHORING CANDIDATE - NOT RELEASE COPY`

Use this router to load one useful part of the AI Growth Package. Do not ingest
the whole guide, every template, or completed buyer artifacts into one session.

## First Read

1. Read `PACKAGE-INDEX.json`.
2. Ask which outcome the buyer wants now.
3. Select the smallest matching module manifest from `modules/`.
4. Read only that module's guide part, named templates, accepted input
   artifacts, and current buyer `STATUS.md`.
5. State what is known, assumed, and unknown before proposing work.

Never request credentials, secret values, private source files, or unrestricted
system access. Prepare or read by default. A send, publish, spend, delete,
permission, deployment, or other consequential action requires the authority
defined by the chapter and the buyer's current approval record.

| apply one measured loop to the business | `modules/business.json` | accepted technical slice and named business outcome |

If the required input is absent, stop at `BLOCKED`, name one owner task, and
preserve the current state. Do not silently route around a missing approval,
failed restore, unknown external disposition, or unsupported capability.

## Depth

Use the selected depth from Chapter 2:

- `Quick` produces the minimum decision and one next action.
- `Operator` adds safe operation, evidence, and recovery.
- `Builder` adds implementation and verification detail.
- `Architect` adds system boundaries, tradeoffs, and promotion triggers.
- `Lab` adds an isolated experiment with explicit stop conditions.

Depth changes detail, not authority. Do not duplicate a lesson or invent a
second canonical artifact because a deeper route was selected.

## Session Close

Return the artifact path, observed result, blocker or pass state, evidence
references, unresolved risk, and one next owner action. Propose a `STATUS.md`
update, but do not overwrite accepted buyer state without approval.
